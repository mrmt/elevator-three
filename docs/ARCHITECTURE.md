# 構造

`index.html` 1枚で完結する。ビルド工程も依存パッケージもない (two:D-2)。
ファイルは上から順に「CSS」「HTML」「本体 (IIFE)」の3つ。UI の文字列は英語固定で、本体に直書きする (two:D-55)。

現在の実装状況は README を参照。ここには**いま動いているもの**を書く。

バージョンは `VERSION` (tag) と `COMMIT` を持つ。`COMMIT` は `.gitattributes` の `export-subst` で、
`git archive` で配るときに HEAD の短いハッシュへ置き換わる (two:D-81)。置き換わっていなければ番号は出さない。

発音インジケーター (two:D-82) は、発音関数が `markVoice(key, 開始, 終了)` で音声時計の時刻を積み、
rAF の `draw()` から呼ぶ `updateLeds()` が `ctx.currentTime` と比べて mixer のランプ (`#led_<key>`) を灯す。
`markVoice` は `lv(key)>0` でないものを積まないので、バス側で黙らせる音源も MUTE / SOLO に従う。
strings の持続音だけは `apply()` と同じ条件で状態として判定する。ドラム系 (drums 群) は発音の頭の 80ms だけ灯す。mixer に無い reverse はインジケーターだけの行を持つ。

## 進行の3階層

`seqTick()` が先読み 0.12 秒で16分ステップを予約し、小節の頭で `onBar()` を呼ぶ。
`onBar()` が3階層すべての判断を行う。

- **第1層 シーン** — `enterScene()`。長さは `sceneLengthBars()` が `evolution` から決め、
  16小節の倍数に丸める。切り替えはフレーズの切れ目でのみ起きる
- **第2層 フレーズ** — `phraseLen` 小節ごとに `nextPhrase()`。型はシーンの重み `w` から引く。
  `build` が続いたら `drop` へ倒すといった並びの制約もここ。
  「展開」を上げると8小節の折り返しでも切り替わることがある。
  **`break` だけは1小節で抜ける** (two:D-24)
- **第3層 イベント** — 4小節の節目に `maybeEvent()`。フレーズ型で基礎確率が変わり、
  グリッチ系だけ `glitch` スライダーとシーンの `glitch` で二重に重み付けられる

## シーン遷移 (two:D-5)

`startTransition()` が入口で、自動の切り替えと「次へ」の両方が通る。
`pendingScene` に行き先を、`transitionEndBar` に終わりの小節を持つ。
方式は `chooseTransitionMode()` が確率で選ぶ。

BPM は `bpmCur` が `bpmTarget()` へ一定の速さ (時定数6秒) で寄る。遷移中は行き先の
シーンの値が目標になるので、乗り換えの瞬間に拍が飛ばない。

**方式1 ブレイク (8小節)** — ブレイクを置き、その間にキット・和音・編成・BPM を
乗り換える。「次へ」はこの方式に固定で、長さだけ半分の4小節にする (two:D-16)。

**方式2 連続変形 (16小節)** — ブレイクを挟まず、陰陽の目標を行き先のシーンへ
まっすぐ寄せる。回路もキットも同じ相手にしか選ばれない。離散的に入れ替わるものが
無いので継ぎ目が出ない。調も持ち越す (`enterScene(idx,{keepKey:true})`)。

**方式3 DJ ミックス風 (16小節)** — 2本目のドラム経路 (`drumBusB → drumFilterB →
drumMixB`) に、入ってくるシーンのドラムだけを流す。ハイパスを 1.4kHz から下げながら
量を上げ、出ていく側は後半で引く。`buildBar()` をシーン指定で呼べるようにしてあるので、
同じ小節に対して新旧2つの並びを作れる。`kitOverride` が入ってくる側のキットを切り替える。

ベースと和音まで重ねると音がぶつかるので、重ねるのはドラムだけに留める。
DJ が次の曲のビートを差し込むのと同じ範囲。

### 開発用の指定

方式2と3は自動では数分に一度しか起きない。`?transition=break|morph|mix` を付けると
方式を固定できる (テストもこれを使う)。固定した場合は方式2の相性の判定も飛ばす。

たまにしか出ない仕掛けにも同じ手を用意してある。試聴とテストのために要る。

| 指定 | 効き |
| --- | --- |
| `?spark` | キラキラのリフ (two:D-48) を4小節区間ごとに必ず出す。間隔の下限も外す |
| `?dub` | ダブ (two:D-49) を4小節ごとに判定する。シーンの種類も問わない。乗り換え前の小節 (two:D-62) もダブに固定する (`?dub=0` ならオカズ) |
| `?spark=0.5` | 値を 0〜1 で渡すとそれが確率になる。`?dub=0.5` も同じ |
| `?fill=tom` | オカズ (two:D-20) の主役をタムに固定する。`?fill=snare` も同じ |
| `?sparkrhythm=push` | リフの置き場所の型 (two:D-74) を固定する。`quarter` / `push` / `eighth` / `three` / `laid` / `syncope`。引くところを固定するだけで置く規則は素のまま。`push` のときは食いが残る枝 (4小節め) へ寄せる |
| `?sparkmotif` | 覚えた形 (two:D-75) を必ず使い回し、引退もさせない。応答も必ず返す。`?sparkmotif=0` なら必ず新しく引く |
| `?sparkfold=high` | リフの畳み先 (two:D-76) を固定する。`mid` / `high`。音域を上げても量が暴れないかを対にして測るのに使う |
| `?sparkq=18` | リフのレゾナンス (two:D-77) を dB で固定し、Q の動きも止める。0.5〜18 |
| `?sparkcut=2` | リフのカットオフの倍率 (two:D-77) を固定し、動きも止める。0.25〜4 |
| `?sparkrescomp=0.3` | Q の量の補正の係数 (two:D-77) を差し替える。0〜1。係数を往復で比べるのに使う |
| `?sparklow` | リフのメロディ全体を必ず1オクターブ下げる (two:D-79)。`?sparklow=0` なら下げない |

素のままだとリフは毎分1〜2回、ダブは8小節ごとに funk で5割なので、
聴いて確かめるのに何分もかかる。オカズは8小節ごとに来るが、タムかスネアかを
毎回引くので、タムを見たいときは出るまで待つことになる。

この楽器は実時間でしか事象を出さない (125BPM で1小節1.92秒、16小節30.7秒) ので、
**待つのをやめて起こせるかどうかが、試験にかかる実時間をそのまま決める。**

## 陰陽の波 (two:D-13)

`wavePos` が 0〜1 を巡り、`waveYY()` が陰陽値を返す。1周期は 20〜40 分で、
シーンが変わるたびに `newWavePeriod()` が引き直す。次のシーンは波の現在位置に
最も近い5つから引き、直近3つは避ける。この5つのうち別の群 (回路) のシーンへ
80% で渡る (two:D-53)。残りは同じ群へ渡るが、連続変形 (two:D-5 方式2) が成り立つよう
キットまで同じ相手を先に採る。

手で操作したときは逆に `yyToWavePos()` で波の位置を陰陽値に合わせる。
陰陽のスライダーとシーン一覧からの選択がこれを通る。スライダーを掴んでいる間は波が目標を奪わず、放したあとは続きから進む。

## クロック

時計は AudioWorklet (`CLOCK_SRC`) が音声スレッドから約21msごとに叩く。
`setInterval` はバックグラウンドで絞られるが音声スレッドは絞られないため、
画面ロック中も進行が止まらない。AudioWorklet が無い環境では `setInterval` に戻る。

**小節ループ (two:D-56)** — `loopBar` が立っている間、`seqTick()` は小節の頭で `onBar()` を呼ばず、
`barCount` も進めない。`seq` がそのまま繰り返され、`barCount` を見る仕掛けも同じ小節として鳴る。
波・BPM の推移・ミックスのフェードは時間で進むので止まらない。再生を始めて並びを1度作るまで
(`barBuilt`) は、ループを立てていても通常どおり進む。

## 音の経路

```
各打点 → drumBus → drumSat (飽和) → drumPost → drumFilter
                                                  ├→ dry → dubFilter ┐
                                                  ├→ revSend ─────────┤→ mixFilter → master → comp → makeup → clip → destination
                                                  └→ dlySend ─────────┘
```

- `drumSat` の入りは「押し出し」が持ち上げ、`drumPost` がそのぶんを戻す
- `drumFilter` はフレーズ型で開き具合が変わり、`sweep` イベントが一時的に奪う
- `mixFilter` は `masterfilter` イベント専用。普段は開いたまま
- フェーザー (全域通過4段 + LFO) にドラムとシーケンスを通してある。
  普段は wet が 0 で、`phaser` イベントだけが持ち上げる (two:D-28)
- ディレイは左右で時間の違う2系統。16分3つと16分5つで、どちらもグリッドに乗る (two:D-15)
- `dubFilter` は `dry` と `mixFilter` の間にある。dub (two:D-49) の1小節だけ閉じる。
  リバーブとディレイの返しは `mixFilter` へ直に入るので、ここを閉じても返しは残る
- dub の間だけ、ディレイのフィードバックと出力を上げて返しを育て、小節末か
  次の小節の1拍終わりで 0 に落とす。`apply()` は `evDelayUntil` の間ここに触らない

イベントがフィルタを動かしている間は `apply()` が触らないよう、
`evFilterUntil` / `evMasterUntil` / `evDelayUntil` に「いつまで奪っているか」を音声時計で持つ。

## ドラム音源 (two:D-10)

打点ごとにオシレータを立てると数が多くなるので、ノイズと金属質の倍音列
(矩形波6基の非整数比) は起動時に1本ずつ焼き、打点では読み出しと包絡だけを作る。

`bd` `sd` `cp` `hh` `cy` `cb` `rim` `perc` の8つ。キット (`KITS`) が
バスドラムのピッチ落ちと減衰、スネアの胴とノイズの比、ハットのハイパスと減衰、
パーカッションの作り方 (ノイズ / 金属 / FM) を振り分ける。

鳴り終わったノードは `disposeAt()` に積み、音声時計から `runDisposals()` が切り離す。
`setTimeout` に載せると、絞られた環境で発火しないクロージャがノードを掴んだまま溜まる。

## ベース (two:D-10)

two の中核。経路は
`bassSum → bassPre (押し出し) → bassShaper (飽和) → Ladder → bassAmp → bassComp → bassBus`。

- 打点ごとに立てるのは矩形波だけ。±7cent でデチューンした3基と、1オクターブ下のサブ。
  矩形波は1本のオシレータでは作らず、**鋸波とその遅延の差**で作る。遅延の長さが
  そのままパルス幅になるので、そこを LFO で揺らすとパルス幅変調になる (two:D-18)
- 単音なので、振幅とフィルタの包絡は共有の段に持たせる。
  持続する音色は、頭を出したあとサスティンを頭の半分まで落としてから伸ばす (two:D-43)。
  1音ごとにカットオフを大きく開けてから短い時間で閉じる。長さより落差を優先する。
  キックと重なる位置ではアクセントで開き幅が増す
- ゆっくりした LFO が Ladder のカットオフへ直接繋がっている。
  「ベースラインにフィルタが揺れ動く」の土台
- ベース専用のフェーザーを持つ。1小節の音符数が5未満のときだけ wet を上げ、
  そのぶん量を1割下げる (two:D-39)。全体に掛かるフェーザー (two:D-28) とは別系統
- 1小節に出る音程が2種類以下のときは `bassWobble` が立ち、1音ごとにフィルタの
  開き幅・落ち着き先・レゾナンスを振る (two:D-42)。この間 `apply()` はレゾナンスに触らない。
  音程数は音名で数え、持続する音色なら1音ごとに25%で音程にも揺らぎを掛ける (two:D-51)
- 持続する音色では、どのシーンでも同じ音程が続いた打点を35%でオクターブ動かす。8割は上、2割は下 (two:D-51)
- コンプは threshold -22 / ratio 6 / attack 4ms と深く速い。「厚めのコンプが効いた音」

### Ladder フィルタ

4段の一次ローパスに負帰還をかけ、各段を `tanh` で飽和させる古典的な構成を
AudioWorklet に置いた。BiquadFilter の多段近似ではレゾナンスを上げたときの
粘りと飽和が出ないため。単一ファイル方針は Blob URL で保つ (時計と同じ手)。

`cutoff` は a-rate なので LFO と包絡を直接繋げる。Worklet が使えない環境では
BiquadFilter 2段へ落ちる (粘りは出ないが鳴りはする)。

## ハーモニー3回路 (two:D-8 / two:D-9)

汎用の和音生成器のパラメータ違いではなく、別々の経路として持つ。
鳴らすのは基本的にどれかひとつで、どれを使うかはシーンの群が決める (`circuit()`)。

**持続回路 (陽)** — `padLayer[0..3]` の4層。下2層は和音が変わるたびに組み直す
持続音 (鋸波と三角波のデチューン + コーラス)、上2層はアルペジオと高域リフで
打点ごとに鳴らす。持続音は前に出やすいので、上の層より低く敷いてある (0.55 対 0.7)。層の数は `padLayers()` が返し、`build` のフレーズで16小節かけて
1層ずつ増え、`drop` で天井に達してから剥がれる。electro funk のシーンでは1層だけ薄く敷く。

**スタブ回路 (陰)** — 裏拍に短く刺す鋸波の和音。原音は22%しか出さず、
ディレイへのセンドが90%。フィードバックとフィルタが表情の中心になる。

**ジャズ / ボッサ回路 (彩り)** — Rhodes 系のエレピ (two:D-68)。正弦波を同じ周波数の正弦波で変調する FM で、
変調の深さは頭で深く約60msで浅くなり、強さに比例する (弱いと丸く、強いと明るく歪む)。
比 14 の変調を頭の約12msだけ足して打鍵のカチッを出す。減衰は音価の24% (最大150ms) で、two:D-41 より少しだけ長い。
和音1つにつき1回、`epThump()` が打鍵の低い衝撃音 (三角波、170Hz → 80Hz、約30ms) を足す。
厚みは後段のコーラス (4.2ms / 7.1ms のディレイを左右で揺らす、two:D-40) で作る。
ルートを省いて3度と7度にテンションを足した積み方 (`rootlessNotes`) を使う。
主役のシーンを持つほか、`epGuest` が立っている間は他のシーンへも短く差し込む。

**コード弾きの連打 (two:D-34)** — 持続回路のもうひとつの姿。持続音の代わりに、
サステインを持たない短い和音 (約85ms) を8分中心に連打する。専用の ping-pong
ステレオディレイへ送り、原音より返しのほうが多く鳴る。連打のときは下2層
(持続音) を止め、アルペジオと高域リフはそのまま乗せる。
どちらになるかはシーンの `chop` の値で決まる。

**16分のシーケンス (two:D-21)** — ハーモニーとは別の層。ディケイの短いアナログシンセの音で
16分を刻む。音色は小節ごとに 25% の確率で差し替わる (鋸波が基本、矩形波・三角波・
細いパルス)。1音ごとにフィルタを叩いて短く閉じる。

専用のステレオディレイを持つ。左右で16分3つと5つ、返しを互いに送り合う ping-pong 型で、
`build` の局面でいちばん深くなる。盛り上げる局面だけ像が左右へ開いていく。

**キラキラのリフ (two:D-48)** — 4番目の独立した回路。鋸2基と矩形1基に、速さの違う
2本の LFO を共通で `detune` へ掛けて濁らせ、Juno のコーラス (two:D-40) と同じ後段を通す。
これに非整数比で変調した FM のベルを重ねる。ベルだけはローパスを通さず VCA の
後ろへ直に入る。4フィート。サスティンを持たず短いディケイだけで落ちる。

出すかどうかは `planSpark()` が4小節区間の頭で決め、**置き場所の型もそこで引く** (two:D-74)。
`regenerate()` → `placeSpark()` が `seq.spark` に置く。置き場所は「小節頭から数えた16分の
オフセット」1本の列で、負なら前の小節の終わりへ食い込み、16以上なら次の小節へはみ出す。
`seq.spark` は `placeSpark()` の専有で `buildBar()` は返さないので、任意のステップに置いても
`Object.assign` で潰れない。はみ出しは `sparkSpill` が `{i,nt}` の配列で持つ
(オカズの `pendingSpill` と同じ形)。

`onBar()` はその小節のステップ0を予約する直前に走るので、**前の小節へは後から書き戻せない。**
食いは `sparkAt-1` の小節を処理しているときに置く。

旋律は頭の音と跳んで着いた音を 50% / 40% で1オクターブ下へ落とし、アクセントにする
(two:D-52)。続けては落とさない。
確率は BPM から逆算するので、拍が変わっても毎分1〜2回に保たれる。型は区間の中のどこに
置くかしか変えないので、毎分の回数には効かない。

**モチーフと応答 (two:D-75)** — `sparkMotif` が直前のリフの形を覚える。持つのは半音ではなく
`tones` の添字の差分なので、開始位置を引き直せば同じ形がそのときの和音の上で鳴る
(移調と再和声化が別処理なしで付いてくる)。旋律は `drawSparkLine()` が新しく引き、
`motifLine()` が覚えた差分から組み、どちらも `sparkVoice()` が two:D-52 のアクセントを付ける。
`varyMotif()` の変奏は `steps` か `rhythm` の片方だけを触る。
使い回しは 2〜4回で引退し、シーンが変わると `enterScene()` が捨てる。

呼びかけが出ると 35% で `sparkAnswerAt` に次の区間の2小節めが入り、その区間の頭で
`planSpark()` が新しく引く代わりに変奏を組む。応答は確率と間隔の下限を通さないが、
応答からは繋げない。応答は `sparkAt=bar+1` になるので食いが使えず `quarter` に落ちる。

**音域と群の性格 (two:D-76)** — 畳み先は `SPARK_FOLDS` の2段 (4フィート 70〜89 と、その上の 75〜94) から
回ごとに引く。下へは振らない (two:D-48 の性格が薄れ、two:D-52 のオクターブ下げがベースの域まで降りる)。
`SPARK_PROFILE` が群ごとに音数の幅・畳み先の重み・型の重み・ベルの量・音価を持つ。
`SCENES` の行には置かない。性格は群ごとで、シーン固有の値ではないため。
重みは `wpick()` が引く (`choosePhrase()` が `SCENES` の `w` を読むのと同じ形)。
音価とベルの量はノートに載り、`sparkNote()` の第4引数で受ける。

**音色 (two:D-77)** — `drawSparkTimbre()` がリフ1回ごとに `dec` / `cut` / `env` / `q` の組と、
フレーズ内の動き (`SPARK_CUT_SHAPE` / `SPARK_DEC_SHAPE` / `SPARK_Q_SHAPE`) を引く。
`planSpark()` が音の位置で形を掛けてノートに載せ、`sparkNote()` の VCF と VCA が受ける。
応答は `sparkTimbre` を引き直さず、呼びかけと同じ組を使う。
lowpass の Q は dB なので、Q が 4 を超えたぶんだけ VCA を `RES_COMP` (0.3) で下げる。
ベルはフィルタを通らないので補正の外。
ベルはフィルタを通らないまま、ノートの `cut` で変調の深さを、`q` で変調の残り方を変える (two:D-78)。
`sparkLow` が立った回はメロディ全体を1オクターブ下げ、two:D-52 のアクセントは付けない (two:D-79)。応答は呼びかけの `sparkLow` を引き継ぐ。

### 和音

`QUALITIES` が品質ごとの構成音、`PROGS` が回路ごとの進行、`CHORD_BARS` が
和音の変わる間隔を持つ。スタブは8小節に一度しか動かず、ジャズは2小節ごとに動く (two:D-67 で従来の半分にした)。
シーンが変わると進行を選び直す。

## インダストリアル・ノイズ (two:D-38)

ドラムやシーケンスとは別に、小節に乗らない周期で回る層を持つ。
`noiseGens` が生成器の配列で、それぞれ `len` (16分に換算した周期) と `pat` を持つ。
`playStep()` が通し番号 `barCount*16+i` を周期で割った位置を見るので、
小節をまたぐたびに位置がずれる。

`makeNoiseGen()` は 16 の約数になる長さを引き直す。それだと小節にそのまま乗ってしまう。

音色は `industrialHit()` が1音ごとに振る。素材・再生速度・フィルタ・減衰を毎回引くので
同じ音は二度と出ない。出すかどうかと左右の構成はシーンに入るたびに `rollNoise()` が引く。

## 調性 (two:D-9)

`keyPc` が主音のピッチクラスを持ち、シーンが変わるたびに五度圏で近い調へ移る。
音階は主回路の群ごとに変える (`SCALES`)。ハーモニー3回路とベースが同じ場所を見る。

ベースは音階ではなく、**いま鳴っている和音の構成音**から度数を引く。ルートが最も厚く、
小節頭は必ずルートになる (two:D-17)。ルート以外の音は1小節にひとつだけ選んで使い回すので、
和音が変わるまでは同じ音が続く (two:D-19)。12%の確率で和音から逸れるが、そのときも音階の中から選ぶ。

**音域の基準は12の倍数で取ること。** `chordNotes(base)` は `base+keyPc+chordDeg` を
ルートにするので、base が C 以外だと鳴る音名が調とずれる。
実際、ベースが 28、スタブが 52 を基準にしていて音名がずれていた。

## 平行移動の転調と開いた和声 (two:D-65 / two:D-66)

**主音** — 音程を出す箇所はシーンの調 `keyPc` を直接読まず、`tonic()` (= `keyPc + shiftOff`) を通す。
`shiftOff` は `onBar()` が8小節の節目に動かし、シーンに入ると 0 に戻る。動いた小節では `chordAt` を戻して、
同じ度数のまま和音を組み直す。積み上げから戻しへ抜けるときの全音上げは `nextPhrase()` が `keyPc` を直接上げる。
ペダルは `pedalPc` / `pedalUntilBar` を `bassBar()` が見る。

**開いた和声** — `lushOn` が立っている間、`pickProg()` は `LUSH_PROGS` から引き、和音は `LUSH_CHORD_BARS` (8小節) ごとに進む。
`lushOn` は `rollLush()` がシーン入りと16小節ごとに引き、jazz / sustain 以外では立たない。
和音の要素は `[度数, 種類, 低音の度数]` で、低音があれば `chordBassDeg` に入り、ベースはそれを踏む。

- `voicedNotes()` が開いた配置を返し、`leadVoices()` が前の配置に近いオクターブへ揃える
- `padRebuild()` は、`lushOn` で声部の数が同じなら、持続音を入れ替えずに各オシレータの周波数を滑らせる。
  `padVoices[].osc` は声部ごとの [デチューン2本] で、`notes` にいまの配置を持つ
- `padInnerLine()` が内声の半音の動きを周波数の予約で入れる
- アルペジオ・高域リフ・リフは `coreNotes()` を使う。`lushOn` でなければ `chordNotes()` と同じ

## リズム生成 (two:D-7)

`regenerate(bar)` が小節ごとに `seq` の9トラックを引き直す。フレーズとシーンが
先に決まってから呼ばれる (両者が並びの前提になるため)。

並びは疑似乱数の**種** (`patSeed`) から決まるので、種が同じなら同じ並びが出る (two:D-14)。
種が変わるのはシーン・フレーズの切り替わりと、変異が当たったときだけ。
偶数小節と奇数小節では種をずらし、2小節でひと組の顔にする。

- **キック** — 4つ打ちを基本堅持。`bar%8===7` の節目でのみ変形演算子
  (抜き / 食い / ダブル / ゴースト) をひとつ当てる。小節頭は変異させない。
  electro funk のシーンだけ `FUNK_KICK` の辞書から引く
- **スネア / クラップ** — 2・4拍。キットが electro か funk のシーンならクラップ。
  funk ではゴーストを足す
- **ハット** — `euclid(k,16)` を回転させ、密度で間引き、拍で強弱を付ける。
  オープンハットは裏拍にひとつだけ、位置は毎小節引き直す。
  13%の確率で直後に32分をひとつ足す (two:D-47)
- **パーカッション** — 互いに素な周期を通し番号 (`bar*16+i`) で回す。
  小節をまたいで模様が変わる
- **ベース** — 専用の乱数を持ち、種が変わるまで同じ旋律を繰り返す (two:D-30)。
  判定に使う陰陽と密度は 0.1 刻みに丸める。位置と音価をシーンの陰陽から決め、
  陰は8分以下でまばら・音価が長く、陽は16分で細かく刻む。
  electro funk のシーンだけシンコペーションの格子を使う。
  音色はシーンごとに、持続する音とタイトな音のどちらかを半々で引く (two:D-25)
- **乗り換え前の小節 (two:D-62)** — `onBar()` が遷移の直前の小節で、40% でダブ (`dubAt` をその小節に置く)、
  それ以外はオカズを引く。ダブのときはブレイク方式でもブレイクにしない。オカズのときはブレイクの中でも
  オカズを置く (`isFillBar()` がブレイクより先にこの小節を見る)
- **オカズ (two:D-20 / two:D-47)** — 8小節の折り返しの直前と遷移の直前の小節。小節の終わりから
  3〜10ステップぶんを使い、タム主体かスネア主体かを引く。休符の出やすさ・音程の並び・
  強さをそのつど振り、22%で32分の詰めを足す。35%の確率で次の小節へ
  はみ出す (`pendingSpill` が次の小節に足される)
- **16分のシーケンス (two:D-21)** — 和音の構成音から2〜3個に絞った音を16分で刻む。
  全体にかかるフィルタが別にあり、`leadsweep` イベントが上げ下げする。
  35%の確率でレゾナンスを18まで上げて発振寸前まで持っていく (two:D-29)
- **変異** — `mutate` が種を引き直す確率 (two:D-14)

## 見た目 (two:D-37)

EK (ダーク & サイバネティクス) 固定。テーマの切り替えは廃止した (2026-09-12)。

波形の色 (`--scope`) は CSS 変数が持つ。
毎フレーム `getComputedStyle` を呼ぶと重いので、起動時に `readLook()` が1度だけ拾う。
この関数は `scopeColorCache` の宣言より前に置かれているので、呼び出しは初期化の列から行う。

## スライダー卓と個別の音量 (two:D-54)

中央の `#console` の中で `#mixer` がスクロールし、群を上から並べる。
上段の `.ctlrow` に control と monitor が横に並び (狭いと折り返す)、下段が mixer。
`#bigplay` は卓の中央の最前面にある。

**monitor (two:D-61)** — `#rbpm` / `#rbar` (見出しの右)、波形の帯 `#cv`、ステップ列 `#steps`、
進行の表示 (`#pphrase` ほか) を持つ HTML の箱。control の群は本体がその前へ差し込む。

**next と loop bar (two:D-62)** — HTML ではシーン欄に置いてあり、本体が control の master 列の下 (小見出し `scene`) へ移す。
点滅は `showProgress()` がまとめて付け外しする。シーン名は乗り換え前の小節の間、next は押してから乗り換わるまで (`nextPending`)、loop bar は有効な間 (two:D-63)。
点滅は視差効果を減らす設定でも止めない。
`#pbarpos` の末尾には、いまの小節の装飾 (`dub` / `fill`) が出る。

群は control (master / character / motion)・mixer (drums / bass / harmony / riff / texture) の2つと monitor (two:D-57 / two:D-61)。
`mixGroup()` が群を、`mixSub()` が群の中の小見出し付きの列を作る。
`reset all` は、`addSlider()` が登録簿 `sliders` に積んだ既定値へ全部戻し、保存した個別の音量を消す。
陰陽の既定値だけは関数で、いまのシーンの位置を返す。

**SOLO / MUTE (two:D-59)** — 音源側は個別の音量 `mix` を直接読まず、必ず `lv(key)` を通す。
MUTE されているか、どれかが SOLO でそれ以外なら 0、そうでなければ `mix[key]` を返す。
ベルの FM 比率 `mix.bellRatio` だけは量ではないので直接読む。状態は `solo` / `mute` の Set で持ち、保存しない。
行の表示は `refreshSoloMute()` がまとめて揃える。

- スライダーは `addSlider()` が組む。連続パラメータは `paramSlider()` (`(edit)` が付く)、
  個別の音量は `mixSlider()` (付かない)
- 陰陽のスライダーは波やシーン選択でも動くので、掴んでいないときだけ `readout()` が目標へ追従させる
- 個別の音量 `mix` は `localStorage` (`elevator-three:mix`) に保存し、起動時に範囲を確かめて戻す
- 効かせ方は2通り。**ドラムは打点側** — 各発音関数の先頭で `v` に掛け、0 なら何も作らない。
  ミックス遷移の2本目 (`playStepB`) も同じ関数を通る。**それ以外はバス側** — `apply()` が
  `bassBus` (electro funk とそれ以外で別の値) / `padBus` / `chopBus` / `stabBus` / `epBus` / `leadBus` / `noiseBus` に掛ける
- リフは本体とベルを `sparkNote()` の中で別々に掛ける。ベルが 0 ならベルのノードは作らない。
  FM 比率は、1音ごとに引く3値に `mix.bellRatio` を掛ける

## オシロスコープ (two:D-36)

出力の最終段 (`out`) から `AnalyserNode` へ分岐し、`draw()` が monitor の帯 `#cv` に波形と拍の明滅を描く (two:D-61)。
上りのゼロ交差を起点にするので、波形が横へ流れずその場で形が変わる。
